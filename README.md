# Pattu Kutti — 365 Days of Us ❤️

This is a self-contained anniversary website.

## GitHub Pages
1. Create a public repository, e.g. `pattu-kutti-365-days`.
2. Upload `index.html`.
3. Open Settings → Pages.
4. Select Deploy from a branch → `main` → `/ (root)`.
5. Save and wait for the GitHub Pages URL.

The website is designed for phones and desktops and does not require a server.
